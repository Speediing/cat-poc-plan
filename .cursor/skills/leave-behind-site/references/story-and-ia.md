# Story and IA

## Reader model

A leave-behind is forwarded. Design for four skim paths at once (names change per account):

1. **Executive sponsor** — did we understand them; is the ask small and owned?
2. **Builder / R&D lead** — is the work self-contained but real?
3. **Platform / MLOps / security** — path to production, not a sandbox demo?
4. **Budget reviewer** — funding shape in plain terms, zero invented ROI?

Each person must get their answer from headings + a few cards without reading the whole page.

## Arc rules

- Order is emotional, not alphabetical: earn trust before you propose; propose before you ask for calendar time.
- **What we heard** is synthesized truth, not minutes. Cut attendee logistics, recording links, and “we discussed…”.
- Name tensions honestly (e.g. self-contained vs representative). Resolving a tension the customer voiced builds more trust than a tidy pitch.
- **Who Cursor is** stays short — only differences that hit *their* delivery cycle.
- **Where it plugs in** maps to *their* stages (intake → design → build → review → release). Same path, remove waiting. Do not invent a new operating model for them.
- **Proposed work** must be self-contained, have acceptance criteria, and reuse into something they already care about.
- **Pilot terms** stay operational: window length, who pays tokens, time-to-stand-up, what “done” means. No procurement novel.
- **Timeline** is near-term motion already agreed or obviously next — not a 12-month Gantt.
- **Next steps** are owner-stamped verbs. Separate from vision/scale sections so the page can end concrete without shrinking the ambition section above.

## Numbering and visibility

- Visible sections number continuously (`02`…`0N`). Hero is unnumbered cover.
- Removed beats: delete from `content`, `sections`, page compose, and nav.
- Soft-hidden beats (waiting on a name/confirm): keep full copy in a named export (`hiddenGroup`, etc.) with a `HIDDEN until …` comment; do not mount; do not include in `sections`; renumber as if absent.
- Nav labels stay short (2–3 words). Headings carry the argument in sentence case.

## Handoffs

Optional one-sentence bridges between beats help skimmers. Prefer plain cause→effect over clever transitions.

## Cuts that almost always improve the page

- Product datasheets, model comparison tables, editor screenshots
- Other-customer logos/testimonials
- Security certification walls (one line + “available on request”)
- Org charts, seat-count projections, unsigned “partnership” framing
- Parallel-org gossip that can travel badly when forwarded
